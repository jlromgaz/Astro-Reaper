# 🚀 Astro Reaper

A **2D survivors-like space auto-shooter roguelite** built in **Godot 4.6** with **GDScript** for Android.

> *"Soy una nave pequeña pero cada minuto mi build se vuelve absurda y espectacular."*

## 🎮 Genre

**Survivors-like space auto-shooter roguelite** — inspired by Vampire Survivors / Brotato, but with retro pixel-art spaceships.

## 🛠️ Tech Stack

- **Engine:** Godot 4.6
- **Language:** GDScript
- **Platform:** Android (landscape)
- **Controls:** Virtual joystick + auto-fire
- **Resolution:** 320×180 / 480×270 scaled
- **Art style:** Retro pixel art

## 📁 Project Structure

```
├── agents/          # AI agent role definitions
├── assets/          # Art, audio, fonts
│   ├── art/         # Ships, enemies, bullets, UI, backgrounds, FX
│   ├── audio/       # SFX, music
│   └── fonts/
├── data/            # Tunable content (weapons, enemies, upgrades, balance)
├── docs/            # Design documents and skills
├── scenes/          # Godot scenes
├── scripts/         # Gameplay logic
├── tests/           # Test scenes and scripts
├── .agents/         # Antigravity config, reports, skills
├── AGENTS.md        # AI agent directives
└── README.md
```

## 🎯 Core Loop

1. Enter a run → 2. Auto-fire → 3. Dodge & collect XP → 4. Level up → 5. Choose upgrades → 6. Build scales → 7. Harder enemies → 8. Elites & bosses → 9. Survive or die → 10. Meta-progress
